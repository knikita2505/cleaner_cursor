# MagicSwipe — Обзор приложения

## 1. Общее описание

**MagicSwipe** — iOS-приложение для очистки и оптимизации устройств Apple. Приложение помогает пользователям освободить место на устройстве путём удаления дубликатов фото/видео, очистки контактов, управления медиафайлами и мониторинга состояния устройства.

**Платформа:** iOS (iPhone, iPad)  
**Минимальная версия:** iOS 17.0+  
**Язык:** Swift, SwiftUI  
**Архитектура:** MVVM + Singleton Services  
**Монетизация:** Freemium (подписка через Apphud)  
**Аналитика:** AppsFlyer MMP  

---

## 2. Основные функции

| Функция | Описание | Вкладка |
|---------|----------|---------|
| **Clean (Dashboard)** | Сканирование и очистка медиафайлов: дубликаты фото, похожие фото, скриншоты, Live Photos, burst-фото, большие файлы, видео | Clean |
| **Swipe Clean** | Tinder-подобный интерфейс для быстрой сортировки фото по месяцам (свайп влево — удалить, вправо — оставить) | Swipe |
| **Contacts Cleaner** | Поиск и удаление дубликатов контактов, контактов без имени/номера, похожих имен, резервное копирование | Contacts |
| **Secret Space** | Защищённое хранилище для фото, видео и контактов с паролем и биометрией (Face ID / Touch ID) | Hide |
| **Device Health** | Мониторинг состояния устройства: батарея, хранилище, производительность, температура | Analytics |
| **Cleaning History** | Аналитика очисток: статистика, графики, рекомендации | Analytics |

## 3. Ключевые преимущества

### Для пользователя
- **Быстрая очистка** — сканирование и удаление дубликатов в несколько нажатий
- **Swipe-интерфейс** — интуитивная сортировка фото по принципу Tinder
- **Безопасность** — Secret Space с биометрической защитой
- **Аналитика** — визуальная статистика очисток и состояния устройства
- **Резервные копии** — автоматическое резервное копирование контактов перед удалением

### Технические
- **Нативный SwiftUI** — полностью нативное приложение без cross-platform фреймворков
- **Кэширование сканирования** — результаты сканирования сохраняются для быстрого доступа
- **Фоновая загрузка** — данные загружаются в фоне для мгновенного отображения
- **Freemium-модель** — бесплатный доступ с лимитом 50 элементов/день, безлимит по подписке

## 5. Архитектурные решения

### Паттерны
- **MVVM** — разделение логики и представления через ViewModels
- **Singleton Services** — сервисы как `shared`-синглтоны для глобального доступа
- **ObservableObject + @Published** — реактивное обновление UI через Combine
- **EnvironmentObject** — DI через SwiftUI environment (`AppState`, `Router`)

### Навигация
- **TabView** — 5 вкладок (Hide, Swipe, Clean, Contacts, Analytics)
- **NavigationStack** — иерархическая навигация внутри вкладок
- **Router** — координатор для sheets и full-screen covers
- **Swipe-жесты** — переключение между вкладками свайпом

### Хранение данных
- **UserDefaults** — настройки, прогресс, история очисток, резервные копии контактов
- **FileManager** — секретные файлы (Documents/SecretSpace/)
- **Keychain** — пароли Secret Space
- **JSON Cache** — кэш результатов сканирования (ApplicationSupport/PhotoCache/)

## 7. Разрешения (Privacy)

| Разрешение | Описание | Обязательное |
|-----------|----------|-------------|
| `NSPhotoLibraryUsageDescription` | Доступ к фото для поиска дубликатов и очистки | Да |
| `NSPhotoLibraryAddUsageDescription` | Сохранение оптимизированных фото | Да |
| `NSContactsUsageDescription` | Доступ к контактам для очистки | Да |
| `NSFaceIDUsageDescription` | Face ID для Secret Space | Нет |
| `NSUserNotificationsUsageDescription` | Напоминания об очистке | Нет |
| `NSUserTrackingUsageDescription` | ATT для персонализации | Нет |
