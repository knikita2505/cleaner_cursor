# Промт для кастомизации: Адаптация шаблона под новое приложение

## Как использовать
Вставьте этот промт, когда нужно создать НОВОЕ приложение на базе этого шаблона, но с другой тематикой, цветами или функциями.

---

## ПРОМТ

```
У меня есть шаблон iOS cleaner-приложения. Мне нужно адаптировать его для нового приложения.

## Параметры нового приложения

### Базовая информация
- Название: [НАЗВАНИЕ]
- Bundle ID: [com.company.appname]
- Описание: [краткое описание]
- Целевая аудитория: [описание]

### Какие функции ОСТАВИТЬ из шаблона (выбери):
- [ ] Clean Dashboard (сканирование и очистка фото/видео)
- [ ] Swipe Clean (Tinder-сортировка фото)
- [ ] Contacts Cleaner (очистка контактов)
- [ ] Secret Space (защищённое хранилище)
- [ ] Device Health (мониторинг устройства)
- [ ] Cleaning History (аналитика)
- [ ] Onboarding (4 экрана)
- [ ] Paywall (подписка)
- [ ] Push-уведомления

### Какие функции ДОБАВИТЬ:
- [описание новых функций]

### Дизайн
- Основной цвет фона: [hex]
- Акцентный цвет: [hex]
- Вторичный акцент: [hex]
- Цветовая схема: dark / light / both
- Иконки: SF Symbols / кастомные

### Монетизация
- Тип: freemium / premium / ads / одноразовая покупка
- Если freemium:
  - Дневной лимит: [число] элементов
  - Какие функции premium-only: [список]
- Планы подписки: weekly / monthly / yearly
- Product IDs: [список]

### Интеграции
- Analytics: AppsFlyer / Amplitude / Firebase / нет
- Подписки: Apphud / RevenueCat / StoreKit2 / нет
- Push: OneSignal / Firebase / UserNotifications / нет
- Другие SDK: [список]

## Инструкция
1. Скопируй структуру проекта из шаблона
2. Замени название приложения на [НАЗВАНИЕ]
3. Обнови AppColors с новыми цветами
4. Удали неиспользуемые Features (если отмечено)
5. Обнови MainTabView (убрать/добавить вкладки)
6. Обнови Info.plist (только нужные permissions)
7. Обнови OnboardingView (тексты и иллюстрации)
8. Обнови PaywallView (новые product IDs)
9. Добавь новые функции (если указаны)
10. Проверь компиляцию
```
