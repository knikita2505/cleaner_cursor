# План: доступ к очистке через подписку + rewarded AdMob

## Решения (зафиксировано)

- Бесплатные 50 элементов в день — убираем.
- Secret Space / Contacts / Analytics — только подписка.
- Онбординг-пейвол — не меняем.
- AdMob прод:
  - App ID: `ca-app-pub-5315661113522929~3480780973`
  - Rewarded unit: `ca-app-pub-5315661113522929/5999684093`
- За 1 ролик — до **500 МБ** (`500 * 1024 * 1024`).
- Партия > 500 МБ: идём **по порядку списка**, берём файл, если влезает в остаток квоты, иначе пропускаем. Остаток остаётся выбранным.
- Файл **> 500 МБ** через рекламу не очищается, только подписка.
- **Не больше 3 очисток за рекламу в календарный день** (локальная дата устройства). После 3-й кнопка рекламы неактивна + подсказка про дневной лимит.
- Нет рекламы / закрыл ролик без reward — без бесплатной очистки, остаёмся в попапе.
- UMP — **делаем в этом релизе** (ATT → UMP → `MobileAds.start()` → preload).

## UMP простыми словами

Это **не** абзац в Terms. Google **сам рисует отдельный экран согласия** у пользователей из ЕС / Великобритании / Швейцарии (один раз, потом помнит ответ).

Что видит пользователь:

- В Европе: после запуска (у нас — логично после ATT) всплывает форма AdMob: «разрешить рекламу / персонализацию» с кнопками принять / отклонить / настроить.
- В Японии, США, большинстве стран вне ЕЭЗ: **ничего не показывается**, реклама идёт как обычно.

Почему нельзя обойтись Terms:

- Google не считает пункт в оферте согласием GDPR/DMA.
- Без этой формы в Европе ролики часто не приходят (no-fill), аккаунт AdMob могут ограничить.

Это не ATT. ATT — «разрешить трекинг» от Apple (уже есть). UMP — «согласие на рекламу» от Google. Нужны оба, если хотим рекламу в Европе.

Форму не верстаем руками: в кабинете AdMob → Privacy & messaging создаётся сообщение, SDK его показывает.

Рекомендация: сделать в том же релизе. Если нет — в Европе кнопка «с рекламой» часто не сработает.

## Целевой поток

```
Подтвердил удаление / сжатие / apply в свайпере
        │
        ├─ premium → вся партия сразу
        │
        └─ не premium
              ├─ 1. Premium-пейвол
              ├─ 2a. Купил / триал → вся партия
              ├─ 2b. Закрыл пейвол → попап
              │         ├─ Upgrade (primary) → снова пейвол
              │         ├─ Ads (secondary), если лимит дня < 3 и есть срез ≤ 500 МБ
              │         │     └─ reward → чистим срез, +1 к счётчику дня
              │         └─ закрыл попап → экран выбора без изменений
              └─ 2c. Нечего взять за рекламу (все файлы > 500 МБ) → только подписка
```

Повторный «очистить» на остатке снова идёт через пейвол → попап.

## Попап (наш стиль, компоновка как у конкурента)

Референс: карточка поверх списка, крестик справа сверху.

1. Строка статистики: слева «Deleted» + 0 (или уже освобождено в сессии — **не нужно**, у нас старт с нуля) / лучше: **Selected** размер и число. У конкурента Deleted | Selected и тонкий прогресс. У нас: **Selected: размер · N items**, без фейкового Deleted=0, чтобы не путать.
2. Заголовок: `Start Cleanup`.
3. Текст: `To delete {size}, upgrade to Premium or watch an ad.`
4. Если партия > 500 МБ: доп. строка — за просмотр очистится до 500 МБ (и на кнопке рекламы — размер **среза**, не всей партии).
5. Primary (заливка, наш CTA-градиент): `Upgrade to Premium`.
6. Secondary (обводка, иконка play): `Delete {sliceSize} with Ads`.
7. Если 3/3 за день: secondary **disabled**, подпись `Daily free cleanup limit reached`.
8. Если реклама не загрузилась: secondary можно оставить активной (повторный tap = retry) или показать `Ad unavailable` — retry + подписка, без бесплатной очистки.
9. Крестик закрывает попап.

Цвета/шрифты — `AppColors` / `AppFonts`, тёмная карточка, скругление как у наших модалок.

## Лимит 3 очистки / день

- Считаем **успешный reward**, не попытку и не закрытие пейвола.
- Ключи UserDefaults: дата (`yyyy-MM-dd`, `Calendar.current`) + счётчик.
- Смена дня → счётчик в 0.
- Premium этот лимит не видит.
- 50/день и `RemainingItemsView` удаляем (дашборд и Swipe Hub).

## Архитектура

`CleanupAccessCoordinator` — единая точка вместо `handleCleaningAttempt` на 9 экранах.

Вход: `[CleanupItem]` (`id`, `byteSize`, порядок UI) + выполнение очистки по id.

`RewardedAdService` — preload, show, reload после показа. Не грузить рекламу premium-пользователю.

`CleanupRewardSheet` — попап.

Размер в квоту 500 МБ:

- удаление: `fileSize`;
- Live convert: экономия с карточки;
- сжатие видео: оценка экономии выбранного качества.

## AdMob

SPM уже есть (`GoogleMobileAds` ≥ 13.9.0). Нет `GADApplicationIdentifier`, список SKAdNetwork неполный.

После получения ID:

1. Прод App ID в `Info.plist` (`GADApplicationIdentifier`).
2. Дописать SKAdNetwork из гайда Google.
3. `MobileAds.shared.start()` после ATT.
4. Прод Rewarded Ad Unit в `RewardedAdService`.
5. Для своего телефона в AdMob — test device, чтобы не крутить боевые клики на своём аккаунте.

## Apple

- Реклама = разовое действие, не Premium (3.1.1 / 3.1.2).
- В описании App Store — что есть реклама.
- Privacy Nutrition Labels + Privacy Policy (AdMob).
- Ролик только по тапу, чистим только после reward.
- 3/день — нормальный честный лимит, не обход IAP.

## Этапы

1. AdMob: plist, init после ATT, `RewardedAdService` (прод ID).
2. Координатор + попап + счётчик 3/день + срез 500 МБ.
3. Подключить экраны медиа-очистки.
4. Снести 50/день и алерты лимита.
5. Локализация попапа (en, ja, es, pt-BR).
6. QA: 80 МБ / 800 МБ / файл >500 МБ / 4-я попытка за день / no-fill / покупка / закрытие пейвола и попапа.
7. Метаданные стора и политика — отдельно, до сабмита.

## UMP

В этом релизе: ATT → UMP → `MobileAds.start()` → preload rewarded. Вне ЕЭЗ форма обычно не показывается.
